🎉 Evently – Event Management Website

Evently is a web-based event management project designed to help users explore events and view event details through a simple, attractive, and user-friendly interface.

✨ Features
🎨 Clean and modern UI
📅 Explore events
🔍 Easy event discovery
📱 Responsive design
⚡ Simple and user-friendly experience

🛠️ Technologies Used
HTML5
CSS3
JavaScript

🎯 Project Goal
The goal of Evently is to provide an easy and engaging way to discover and explore events through a well-designed web interface.
